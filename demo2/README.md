# Переход 2 — Scroll Burn (оптимизированная версия)

Вторая версия демонстрации эффекта **Scroll Burn**: тот же переход, но
с настройками под быстродействие.

**Демо 2:** https://aaateh.github.io/demo/demo2/  
**Демо 1 (исходная версия):** https://aaateh.github.io/demo/

## Что изменено для быстродействия

- Граф SVG-фильтра статичен: параметры `feTurbulence`, `feDisplacementMap`,
  блюров и порога задаются один раз и не меняются на кадре.
- Убраны `feFlood` и `feComposite`: цвет уже есть у заливки, а эти примитивы
  добавляли по полноэкранному проходу фильтра на каждый кадр.
- `will-change: transform` и `visibility` включаются заранее только у секций
  рядом с экраном и снимаются у далёких. Слой готов до начала прожига, поэтому
  первый кадр перехода не тратится на его создание.
- В WebKit/Safari путь кромки строится один раз, а на скролле сдвигается
  `transform`. Раньше строка `d` (несколько КБ) пересобиралась каждый кадр.
- При прыжке по якорю или восстановлении позиции прогресс ставится сразу,
  без обратного прожига через полэкрана.
- `requestAnimationFrame` запускается на скролл и останавливается, когда
  сглаживание догнало цель. В фоновой вкладке — пауза.

## Файлы

```
index.html   — экраны и разметка пульта
burn.css     — стили демо и кромки
burn.js      — прогресс, SVG-фильтр и SVG-фолбэк для WebKit
```

Шрифты берутся из `../fonts/`: Dela Gothic One, Golos Text, Geist Mono
(SIL OFL 1.1, тексты лицензий — в `../fonts/OFL.txt` и `../fonts/NOTICE.md`).

платного компонента.
