# Переход 1 — Scroll Burn

Интерактивная демонстрация эффекта **Scroll Burn**: следующая секция
«прожигает» предыдущую органической кромкой, пока вы скроллите.
Работает в обе стороны, без видео, WebGL и сторонних библиотек.

**Демо:** https://aaateh.github.io/demo/  
**Билеты:** https://aaateh.github.io/demo/tiket/

## Как это работает

- В уходящей секции лежит абсолютный слой `.burn` цвета следующей секции.
- В Chrome цветной слой растягивается через `scaleY(progress)` и к нему
  применён живой SVG-фильтр: `feTurbulence` → `feDisplacementMap` → blur →
  жёсткий порог альфы. Кромка меняется по мере прокрутки.
- В Safari/WebKit 27 полноэкранный живой фильтр не отрисовывается, поэтому
  там кромка рисуется SVG-путём с CSS-заливкой. Цвет берётся из фона
  следующей секции, слой лежит внутри `.burn` и не «плавает».
- Прогресс считается по положению секции относительно вьюпорта и
  сглаживается через `requestAnimationFrame` (инерция). В фоновой вкладке
  цикл останавливается.
- У каждого блока свой seed, поэтому рисунок кромки не повторяется.

## Пульт

Кнопка **«Пульт»** справа снизу открывает параметры: направление,
сглаживание, начало и конец, размер кляксы, шум X/Y, детализацию и seed.
Настройки не сохраняются между перезагрузками; «Сбросить» возвращает
значения по умолчанию для текущего браузера.

## Файлы

```
index.html   — экраны и разметка пульта
burn.css     — стили демо и кромки
burn.js      — прогресс, SVG-фильтр и SVG-фолбэк для WebKit
fonts/       — Dela Gothic One, Golos Text, Geist Mono
```

## Шрифты

Dela Gothic One, Golos Text и Geist Mono распространяются по SIL OFL 1.1.
Тексты лицензий и атрибуция — в `fonts/OFL.txt` и `fonts/NOTICE.md`.
